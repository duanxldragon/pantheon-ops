## 详细开发内容

### 1. ArgoCD GitOps 完整集成

**新增文件**:
- `backend/modules/business/cicd/argocd/client.go` - ArgoCD API Client封装
- `backend/modules/business/cicd/argocd/reconciler.go` - 状态同步Reconciler
- `backend/modules/business/cicd/argocd/webhook.go` - Webhook处理
- `backend/modules/business/cicd/argocd/client_test.go` - 单元测试

**功能特性**:
- ArgoCD Server健康检查
- Application CRUD操作
- Manual Sync / Rollback / Refresh
- Webhook事件处理 (GitHub/GitLab/Gitea)
- 状态自动同步 (每30秒)

### 2. Velero 备份恢复完整集成

**新增文件**:
- `backend/modules/business/k8s/backup/reconciler.go` - 状态同步Reconciler
- `backend/modules/business/k8s/backup/drill.go` - 灾难恢复演练

**功能特性**:
- 备份/恢复状态自动同步 (每60秒)
- 过期备份自动清理 (每小时)
- 灾难恢复演练流程
- 临时Namespace创建与清理
- 演练报告生成

### 3. 告警规则引擎

**新增文件**:
- `backend/modules/business/observability/datasource.go` - Prometheus数据源管理
- `backend/modules/business/observability/alert_rule.go` - 告警规则引擎
- `backend/modules/business/observability/evaluator.go` - 告警评估引擎
- `backend/modules/business/observability/notification.go` - 通知系统

**功能特性**:
- Prometheus数据源注册与连通性测试
- PromQL查询代理
- 告警规则CRUD (支持PromQL/阈值/模板三种类型)
- 内置告警模板 (主机/K8s/App)
- 告警评估引擎 (每30秒)
- 多渠道通知 (Email/Slack/钉钉/企业微信/Webhook)
- 告警历史记录

### 4. 文件分发系统

**新增文件**:
- `backend/modules/business/filedist/models.go` - 数据模型
- `backend/modules/business/filedist/service.go` - 文件管理服务

- `backend/modules/business/filedist/transfer_service_test.go` - 单元测试

**功能特性**:
- 文件上传与SHA-256计算
- SFTP传输引擎
- 并发控制 (Worker池)

- 完整性校验 (SHA-256)
- 权限设置 (chmod/chown)
- 断点续传支持
- 事件日志记录

### 5. 前端UI

**新增文件**:
- `frontend/src/modules/business/filedist/index.ts` - 模块路由
- `frontend/src/modules/business/filedist/api.ts` - API接口
- `frontend/src/modules/business/filedist/FiledistList.tsx` - 文件列表页
- `frontend/src/modules/business/filedist/FiledistDetail.tsx` - 任务详情页

**功能特性**:
- 文件库管理 (上传/列表/删除)
- 分发任务管理 (创建/启动/取消/重试)
- 实时进度展示
- 主机列表与事件日志

## 技术亮点

1. **模块化设计** - 每个功能模块独立，便于维护和扩展
2. **Reconciler模式** - 参考Kubernetes控制器模式，实现状态自动同步
3. **Worker池模式** - 文件分发使用并发Worker池，提高传输效率
4. **SHA-256校验** - 确保文件传输完整性
5. **Webhook支持** - 支持GitHub/GitLab/Gitea Webhook

## 部署依赖

### ArgoCD集成
- ArgoCD Server (用户自建)
- Git 仓库 (GitHub/GitLab/Gitea)

### Velero集成
- Velero Server (需在 K8s 集群中安装)
- S3 兼容存储 (MinIO/AWS S3/OSS)

### 告警系统
- Prometheus (数据源)
- SMTP 服务器 (邮件通知)
- Slack/钉钉/企业微信 (可选)

### 文件分发
- 本地存储 或 S3
- 目标主机 SSH 访问
