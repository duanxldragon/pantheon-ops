# Design Document Index

Chinese version: [README.md](./README.md)

This is the entry point for `docs/designs/`.

The Chinese index remains the primary reading surface for local development. This English index exists to help international collaborators locate the main design anchors quickly.

Coverage is falsifiable: the directory holds **62 Chinese primary design documents** (this index and the `.en.md` companions are not counted), and every one of them is referenced below. English companions exist for **57 of the 62**; the remaining 5 are Chinese-only and are labeled as such instead of being claimed.
