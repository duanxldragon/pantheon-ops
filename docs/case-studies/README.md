## How to Contribute a Case Study

### For Pantheon Base Users

If you've deployed Pantheon Base in production and would like to share your experience:

1. **Use the Template**: Start with `TEMPLATE.md` in this directory
2. **Gather Information**: Collect architecture details, metrics, and feedback
3. **Get Approval**: Ensure you have permission to share the information
4. **Submit**: Create a Pull Request or contact the maintainers

### What to Include

**Essential**:
- Architecture overview
- Deployment specifications
- Key features used
- Performance metrics (if available)
- Benefits realized

**Optional**:
- User testimonials
- Challenges faced
- Future plans
- Screenshots/diagrams

### Anonymization

If you prefer to remain anonymous or cannot disclose company details:
- We can generalize information
- Use industry/size instead of company name
- Focus on technical details rather than business specifics

## Template Structure

Each case study follows a standard structure:

1. **Executive Summary** - Quick facts and overview
2. **Background** - Company context and challenges
3. **Architecture** - Technical deployment details
4. **Implementation** - Timeline and process
5. **Features** - What was used and how
6. **Performance** - Metrics and benchmarks
7. **Benefits** - Results and outcomes
8. **Lessons** - Challenges and best practices
9. **Future** - Planned enhancements

See `TEMPLATE.md` for the complete structure.

- **File Format**: Markdown (.md)
