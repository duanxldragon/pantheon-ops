## 文档说明

### 目的
本文档定义了 Pantheon-Ops v1.2.0 版本的质量验收标准，用于指导 QA 团队进行功能验收测试。所有列出的功能点必须逐一验证，不得遗漏。

### 验收原则
- ✅ **功能完整性**: 所有功能点必须按照规格实现
- ✅ **数据准确性**: 数据展示和处理必须准确无误
- ✅ **性能达标**: 响应时间和并发能力符合要求
- ✅ **安全合规**: 敏感信息加密，权限控制正确
- ✅ **用户体验**: 操作流畅，错误提示清晰

### 验收标准
- **P0 (阻塞性)**: 必须通过，否则不能发布
- **P1 (重要)**: 必须通过，影响主流程
- **P2 (一般)**: 建议通过，不影响发布
- **P3 (次要)**: 可选，体验优化

## 模块 A: ArgoCD GitOps 集成

### A.1 ArgoCD 服务器管理 (P0)

#### A.1.1 添加 ArgoCD 服务器
- [ ] **功能点**: 能够添加新的 ArgoCD 服务器
- [ ] **API 端点**: `POST /api/v1/argocd/servers`
- [ ] **请求参数验证**:
  - [ ] name 必填，长度 1-128
  - [ ] clusterId 必填，必须是有效的集群 ID
  - [ ] endpoint 必填，必须是有效的 URL 格式
  - [ ] authToken 必填
- [ ] **功能验证**:
  - [ ] 服务器创建成功，返回服务器 ID
  - [ ] authToken 加密存储（数据库中不是明文）
  - [ ] 创建时间、创建人正确记录
  - [ ] 返回的 authToken 字段为空（不返回敏感信息）
- [ ] **错误处理**:
  - [ ] 重复名称返回错误
  - [ ] 无效的 clusterId 返回错误
  - [ ] 无效的 URL 格式返回错误
- [ ] **数据验证**:
  - [ ] 数据库中 auth_token 字段已加密
  - [ ] 加密后的值长度大于原始值
  - [ ] 加密值包含版本前缀 "v1:"

#### A.1.2 测试 ArgoCD 连接
- [ ] **功能点**: 测试 ArgoCD 服务器连接性
- [ ] **API 端点**: `POST /api/v1/argocd/servers/:id/test`
- [ ] **功能验证**:
  - [ ] 成功连接返回 200 和成功消息
  - [ ] 连接失败返回 500 和错误详情
  - [ ] 调用真实的 ArgoCD API `/api/version` 端点
  - [ ] authToken 自动解密并用于认证
  - [ ] 更新服务器状态为 "healthy" 或 "unhealthy"
- [ ] **超时处理**:
  - [ ] 30 秒超时设置生效
  - [ ] 超时返回明确错误信息

#### A.1.3 查询 ArgoCD 服务器列表
- [ ] **功能点**: 查询所有 ArgoCD 服务器
- [ ] **API 端点**: `GET /api/v1/argocd/servers`
- [ ] **功能验证**:
  - [ ] 返回所有服务器列表
  - [ ] 包含 name, endpoint, status 等字段
  - [ ] 不包含 authToken 敏感信息
  - [ ] 按创建时间倒序排列
- [ ] **分页验证**:
  - [ ] 支持 page 和 pageSize 参数
  - [ ] 返回 total 总数
  - [ ] 分页计算正确

#### A.1.4 更新 ArgoCD 服务器
- [ ] **功能点**: 更新服务器信息
- [ ] **API 端点**: `PUT /api/v1/argocd/servers/:id`
- [ ] **功能验证**:
  - [ ] 可以更新 name, endpoint
  - [ ] 可以更新 authToken（重新加密）
  - [ ] 更新时间正确记录
  - [ ] 旧的 authToken 被覆盖

#### A.1.5 删除 ArgoCD 服务器
- [ ] **功能点**: 删除 ArgoCD 服务器
- [ ] **API 端点**: `DELETE /api/v1/argocd/servers/:id`
- [ ] **功能验证**:
  - [ ] 软删除（deleted_at 字段）
  - [ ] 关联的应用不能操作
  - [ ] 删除后查询列表不显示
- [ ] **级联检查**:
  - [ ] 如果有关联应用，提示不能删除
  - [ ] 或者支持级联删除（根据产品需求）

### D.1 存储管理 (P0)

#### D.1.1 创建存储
- [ ] **功能点**: 创建文件存储位置
- [ ] **API 端点**: `POST /api/v1/filedist/storages`
- [ ] **请求参数验证**:
  - [ ] name 必填，唯一
  - [ ] type 必填（local, s3, oss, minio）
  - [ ] basePath 必填

  - [ ] maxSize 可选，默认 10GB
  - [ ] isDefault 可选，默认 false
- [ ] **类型特定验证 - Local**:
  - [ ] basePath 是有效的目录路径

  - [ ] 有写入权限
- [ ] **类型特定验证 - S3**:
  - [ ] region 必填
  - [ ] accessKeyId 和 secretAccessKey 必填
  - [ ] bucket 必填
  - [ ] endpoint 可选
  - [ ] useSSL 可选，默认 true
- [ ] **功能验证**:
  - [ ] 存储创建成功
  - [ ] 凭证加密存储
  - [ ] 如果 isDefault=true，清除其他默认标记
  - [ ] 创建 basePath 目录（local）

### D.3 分发任务 (P0)

#### D.3.1 创建分发任务
- [ ] **功能点**: 创建文件分发任务
- [ ] **API 端点**: `POST /api/v1/filedist/tasks`
- [ ] **请求参数验证**:
  - [ ] name 必填
  - [ ] fileId 必填，有效的文件 ID
  - [ ] targets 必填，数组，至少 1 个，最多 100 个
  - [ ] scheduledAt 可选（计划时间）
- [ ] **Target 参数验证**:
  - [ ] host 必填
  - [ ] port 可选，默认 22
  - [ ] targetPath 必填
  - [ ] username 必填
  - [ ] password 或 privateKey 必填（至少一个）
  - [ ] maxRetries 可选，默认 3
- [ ] **功能验证**:
  - [ ] 验证文件存在
  - [ ] 任务创建成功
  - [ ] 初始状态为 "pending"
  - [ ] 创建 target 记录，初始状态 "pending"
  - [ ] 凭证加密存储
  - [ ] 如果未指定计划时间，立即执行
  - [ ] 提交到传输引擎

#### D.3.2 执行分发任务
- [ ] **功能点**: 传输引擎执行分发
- [ ] **功能验证**:
  - [ ] 任务状态变为 "running"
  - [ ] 记录开始时间
  - [ ] 并发处理多个 target（最多 5 个并发）
  - [ ] 每个 target 独立传输
- [ ] **单个 Target 传输**:
  - [ ] Target 状态变为 "transferring"
  - [ ] 记录 target 开始时间
  - [ ] 创建 SFTP 连接
  - [ ] 认证（password 或 privateKey）
  - [ ] 创建远程目录（如果不存在）
  - [ ] 上传文件
  - [ ] 更新进度（0-100%）
  - [ ] 传输成功：status = "completed", progress = 100
  - [ ] 传输失败：status = "failed", 记录错误
  - [ ] 记录 target 结束时间
  - [ ] 关闭 SFTP 连接
- [ ] **失败重试**:
  - [ ] 检查 retryCount < maxRetries
  - [ ] 延迟 5 秒后重试
  - [ ] status = "retrying"
  - [ ] retryCount += 1
  - [ ] 重新提交到传输引擎
  - [ ] 达到最大重试：status = "failed"

#### D.3.3 监控任务进度
- [ ] **功能点**: 后台监控任务进度
- [ ] **功能验证**:
  - [ ] 每 5 秒检查一次任务状态
  - [ ] 统计 target 完成数和失败数
  - [ ] 计算任务进度：(completed + failed) / total * 100
  - [ ] 更新任务的 successCount 和 failedCount
  - [ ] 所有 target 完成：
    - failedCount = 0：status = "completed"
    - failedCount > 0 且 successCount > 0：status = "partial"
    - failedCount > 0 且 successCount = 0：status = "failed"
  - [ ] 记录任务结束时间

#### D.3.4 查询任务列表
- [ ] **功能点**: 查询分发任务列表
- [ ] **API 端点**: `GET /api/v1/filedist/tasks`
- [ ] **请求参数验证**:

  - [ ] keyword 可选
  - [ ] page 和 pageSize 可选
- [ ] **功能验证**:
  - [ ] 返回任务列表

  - [ ] 显示任务进度
  - [ ] 显示成功/失败数量
  - [ ] 显示开始和结束时间
  - [ ] 分页正常

#### D.3.5 查询任务详情
