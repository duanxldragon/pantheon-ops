## 执行方式

### 准备工作

1. **安装依赖**
```bash
cd e2e-tests
npm install
npx playwright install chromium
```

2. **配置环境**
```bash
export BASE_URL="http://localhost:8080"
export API_TOKEN="your-api-token"
```

3. **启动服务**
```bash
cd backend
go run main.go
```

### 执行测试

```bash
cd e2e-tests
npm test
```
